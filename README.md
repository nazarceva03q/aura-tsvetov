# Аура цветов

Сайт магазина «Аура» в Оренбурге и общий MAX-бот для обращений и управления каталогом. Домен: https://aura-flower.shop. По сообщению заказчика сайт перенесён на REG.RU; GitHub используется для исходного кода. Перенос статических страниц не переносит обработчик заявок из Yandex Cloud.

Папка `za tsvetkom/` — другой проект. Она не является частью Ауры, её файлы нельзя включать в сборки, документы или публикацию этого проекта. «Бирюза» также использует отдельную инфраструктуру.

Проверки: `npm test`. Сборка архива функций: из `bot/` выполнить `python scripts/build-yandex-zip.py` либо `node scripts/build-yandex-zip.cjs`. Рабочие секреты задаются в переменных Cloud Functions и не входят в репозиторий.
