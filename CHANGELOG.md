# История изменений

## 09–10.11.2026 — очистка Ауры и юридическая подготовка

- Добавлены 30-дневные сроки рабочих данных общего MAX-бота, условные записи Object Storage, квитанции сообщений и отдельная закрытая функция очистки. Защита повторных отправок не продлевает исходный срок.
- Добавлены упаковка обоих архивов без секретов, безопасные коды ошибок хранилища/MAX и проверка удаления служебного сообщения. Технические квитанции ограничены 37 сутками; ограничения MAX и старых сообщений описаны отдельно.
- По результатам пользователя проверены доступ к хранилищу, удаление свежего сообщения MAX, реальная очистка облачных записей и автоматический запуск таймера; расписание возвращено на каждый час.
- Документирована инфраструктура Ауры с размещением сайта на REG.RU по сообщению заказчика. Убрано устаревшее упоминание GitHub Pages в политике и вводящая в заблуждение фраза о согласии одним посещением.
- Добавлены исследование применимых требований, проверенный план, вопросы владелице и подготовка РКН. Оставшиеся задачи: подтверждение реквизитов/процессов и поставщиков, серверное доказательство согласия, условия заказа/возврата, надлежащее подтверждение уничтожения.
- Чужой проект `za tsvetkom/`, локальные предпросмотры, секреты, архивы и данные клиентов в коммит не включаются. Коммит не означает выкладку на REG.RU или подачу РКН.
